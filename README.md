# YouTube Engine | Official Downloads

Welcome to the official distribution repository for **YouTube Engine**, a modern, lightweight desktop application designed to download high-quality audio and video from YouTube with ease.

---

## Download

Get the latest installer from our GitHub Releases page:

👉 **[Download Latest Release](https://github.com/sheilavalencia/youtube_engine.releases/releases/latest)**

1. Under the **Assets** section, download `Youtube_Engine_v1.0.0_Setup.exe`.
2. Run the installer and follow the setup wizard.

---

## Features

- **Multiple Formats**: Extract audio as **MP3** (192 kbps) or **WAV**, and high-definition video as **MP4**.
- **Smart Organization**: Automatically saves files to dedicated Windows folders (`Music/Downloaded_Music` and `Videos/Downloaded_Videos`).
- **No Manual Configuration**: Built-in FFmpeg engine handles conversions and stream merging seamlessly out of the box.
- **Bilingual Interface**: Native runtime switching between **English** and **Spanish**.
- **Modern Design**: Clean CustomTkinter interface with Dark & Light theme options and cat-themed status feedback.
- **Automatic Updates**: Built-in notification when a new official version is released.
- **100% Private**: Runs entirely on your local machine with zero telemetry, tracking, or personal data collection.

---

## System Requirements

- **Operating System**: Windows 10 / Windows 11 (64-bit)
- **Internet Connection**: Required for fetching media from YouTube.
